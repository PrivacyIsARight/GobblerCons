# GobblerCons

The hand-drawn icon language of [gobbler.org](https://gobbler.org).

## v1

The first complete set contains 46 editable SVG icons for chat, memory, voice,
search, reminders, account security, companion devices, reactions, and common
interface actions.

Browse the flat catalog or drive through the 3D icon trail at
[gobbler.org/org](https://gobbler.org/org).

## Use an icon

The source files live in [`icons/v1`](./icons/v1). You can download an SVG
directly from GitHub or reference the raw file:

```html
<img
  src="https://raw.githubusercontent.com/OrchisLabs/GobblerCons/main/icons/v1/brain.svg"
  alt="Memory"
/>
```

The filenames are stable within a version. `calander.svg` and
`news_breif.svg` intentionally preserve their original v1 filenames.

## Design notes

- 30 × 30 view boxes
- Rounded, expressive strokes
- Authored fills and color are part of the icon
- SVG source stays editable and works as flat art or extruded 3D geometry
