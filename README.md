# GobblerCons

The hand-drawn interface icons used by [Gobbler](https://gobbler.org), an Orchis Labs project.

GobblerCons is intentionally a little uneven. The set favors recognizable silhouettes and a human line over anonymous, machine-perfect geometry.

## Use

Copy the SVG you need from `icons/light` or `icons/dark`. The files are standalone and editable; no package or build step is required.
